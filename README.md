## 🚀 Projects

### 🚗 Car Rental System

A menu-driven car rental system with separate **Admin and Customer panels**.

**Admin**

* Secure admin authentication
* View available cars
* Add new cars
* Remove cars

**Customer**

* View available cars
* Rent cars
* View rented cars
* Search/manage rental operations

Built to practice **OOP, encapsulation, inheritance, polymorphism, and real-world object relationships**.

---

### 👨‍💼 Payroll Management System

An employee payroll system supporting different types of workers.

**Features**

* Full-time and part-time workers
* Employee management
* Salary calculation based on worker type
* Employee records using `ArrayList`
* OOP-based employee hierarchy

Built to practice **inheritance, polymorphism, collections, and dynamic salary calculation**.

---

### 🏧 TahaMasterATM

A Telegram-based ATM simulation that allows users to perform ATM operations directly through **Telegram messages**.

**Features**

* PIN authentication
* Change PIN
* Cash withdrawal
* Cash deposit
* Debit/cash transactions
* Telegram-based interaction

Designed to simulate the experience of using a real ATM through a **Telegram bot interface**.

---

### ⚡ Electricity Bill System

A billing system designed to calculate electricity bills based on different customer categories.

**Features**

* Rural and urban area billing
* Different billing calculations based on area
* GST calculation
* Government discounts
* Additional billing rules and charges
* Automated final bill calculation

Built to practice **conditional logic, calculations, OOP, and real-world billing rules**.
